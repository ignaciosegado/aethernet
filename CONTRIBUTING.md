# Contributing to AETHERNET

Thank you for your interest in contributing to AETHERNET.

## Bug Reports & Benchmark Improvements
* Open an issue describing the exact reproduction command, dataset sequence, and expected vs. observed metrics (`RMSE`, `p95`, `NEES`, `NIS`).
* Ensure all existing unit tests pass (`pytest`) before submitting a pull request.
